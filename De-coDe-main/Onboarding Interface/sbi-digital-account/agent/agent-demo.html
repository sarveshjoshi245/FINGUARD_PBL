💡 Integration Guide

To add this agent to your actual dashboard, just include these 2 lines: 
<link rel="stylesheet" href="agent-widget.css">
<script src="agent-widget.js"></script>
Then call window.SBIAgent.setStep(n) when the user moves between steps.
